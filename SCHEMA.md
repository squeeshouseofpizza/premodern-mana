# premodern_lands.json

Every land legal in Premodern, classified by hand against its oracle text. 199 cards,
which is the full count returned by Scryfall for `f:premodern t:land` (the two banned
lands, Strip Mine and Tolarian Academy, are excluded by that query). The Premodern card
pool is frozen, so this file is finished rather than maintained.

Nothing here was derived by pattern matching on oracle text. Each card was read and
decided individually, and the `notes` field records why.

## Companion file

`premodern_lands_heuristics.json` holds deck-profile opinions for cards whose real output
cannot be read off the card, such as Gaea's Cradle. It is generated by a script whose
scope rule asserts against this file, so the two cannot drift apart. If they ever
disagree, this file is right.

## Top-level fields

| field | meaning |
| --- | --- |
| `name` | Card name, exactly as Scryfall returns it. |
| `first_printing` | Set code of the oldest printing. **Not a legality claim.** Ten cards show `FEM` and are legal through Fifth and Sixth Edition reprints; Gaea's Cradle shows `JGP` and is legal through Urza's Saga. |
| `supertypes` | `Basic`, `Snow`, `Legendary`, or empty. |
| `land_types` | Subtypes: `Plains`, `Swamp`, `Lair`, `Urza's Power-Plant`, and so on. Load-bearing. Fetchlands search by land type and the Tainted cycle checks for a Swamp by type, so Snow-Covered Swamp satisfies both. Note the Urza subtype is hyphenated where the card name is not. |
| `enters_tapped` | Boolean. |
| `entry_cost` | What you pay to get it onto the battlefield, or null. |
| `availability` | Card-level restriction on the land being available at all, independent of what you do with it. Only Teferi's Isle uses it, for phasing. Restrictions caused by using an ability live on the ability. |
| `total_activations` | Hard lifetime cap, or null for unlimited. Only six cards are capped: Gemstone Mine at 3 and the Masques depletion cycle at 2. |
| `abilities` | Mana abilities. Empty for the 16 lands that produce no mana. |
| `other_abilities` | Everything else, including abilities usable only from hand or graveyard. |
| `fetches` | Structured description of a library search or hand deployment, or null. 14 cards. |
| `global_effect` | Effects on other permanents. Only Riftstone Portal. |
| `notes` | Reasoning. The reason this file exists. |

## `abilities` entries

| field | meaning |
| --- | --- |
| `produces` | See modes below. |
| `amount` | Total mana produced. `0` when variable. |
| `net_mana` | `amount` minus any mana in the activation cost. Null when variable. This is the number that matters: Aysen Abbey's `{1}, {T}: Add {W}` nets zero and its `{2}, {T}` mode nets minus one. |
| `cost` | Human-readable activation cost. Not intended for parsing. |
| `additional_cost` | Structured non-mana cost that is not sacrificing this land, such as Lake of the Dead eating a Swamp. |
| `self_sufficient` | Can this ability be activated with no other mana available? **False for every filter land.** A calculator asking "can this be my first coloured source" filters on `produces` containing a colour and this being true. This one field prevents the entire Skycloud Expanse class of bug. |
| `condition` | Structured requirement, or null. Types in use: `controls_land_type`, `controls_n_lands`, `controls_other_land_producing_mana`, `controls_coloured_permanent`, `opponent_may_prevent`. |
| `sacrifices_self` | Does activating this ability sacrifice this land. |
| `variable_amount` | Present when the amount depends on game state. Carries `equals`, `accrual`, and `requires_untap_before_use`. |
| `availability` | Restriction that using this ability imposes on future turns. Patterns in use: `every_other_turn`, `skips_next_untap`, `one_activation_per_land_drop`, `requires_upkeep_payment`, `consumes_a_land_per_use`, `consumes_land_drop_each_turn`. |

### `produces` modes

- `fixed` — `mana` is the literal list of symbols produced, all of them, every time.
  Balduvian Trading Post's `{T}: Add {C}{R}` is `["C","R"]`.
- `choice` — `options` lists the symbols, one of which you pick. Always `amount: 1`.
  A painland's `{T}: Add {W} or {U}` is `["W","U"]`.
- `choice_uniform` — `count` mana, all of a single chosen colour. Lotus Vale only.
- `fixed_variable` — `unit` is the single symbol, repeated a variable number of times.
  The storage lands, Gaea's Cradle, Serra's Sanctum, Cabal Coffers.
- `derived` — colours resolve against the board. Reflecting Pool and Meteor Crater.

The `fixed` and `choice` distinction is the single most important thing in this schema.
Both produce two mana symbols in their text and they mean opposite things.

## Invariants

Enforced by the validator on every build:

- `produces.mode == "fixed"` implies `len(mana) == amount`
- `produces.mode == "choice"` implies `amount == 1`
- `self_sufficient` implies `net_mana == amount`
- `variable_amount` present implies `amount == 0` and `net_mana` is null
- every card name matches the Scryfall pull exactly
- all top-level, ability, other-ability and fetches objects share one key set

Variable amounts default to `0` deliberately. A consumer that ignores `variable_amount`
undercounts rather than promising mana that isn't there, which is the safe direction to
fail for a mana calculator.

## Corrections made during the build

Two notes were written wrong and later fixed against rulings rather than reasoning. Both
are recorded in the affected card's `notes`.

- **Reflecting Pool** originally said it ignores lands whose abilities you can't afford
  or whose conditions you don't meet. The opposite is true: the Gatherer rulings say it
  checks the effects of mana abilities but not their costs or legality, so an
  unactivatable Homelands castle or a Tainted Field with no Swamp still feeds it. What it
  cannot do is bootstrap off other Reflecting Pools.
- **Rhystic Cave** originally guessed at a stack-based explanation for its timing
  restriction. The 2004-10-04 ruling says the card carries errata so it cannot be
  activated during the casting of a spell or activation of an ability, so the mana must be
  floated in advance.
